# 服化道参考库 · Costume & Character Reference

面向 AI 短剧 / 影视项目的视觉参考工作台。全部为静态文件，无后端依赖，可直接托管在 GitHub Pages 等任意静态空间。

## 页面

| 文件 | 说明 |
|---|---|
| `index.html` | 落地页：项目定位、参考样张、全库数据概览 |
| `workbench.html` | 工作台：按类型 / 分类 / 风格 / 来源 / 发长 / 地区筛选，支持收藏、上传与详情查看 |

## 数据规模

| 类型 | 数量 | 说明 |
|---|---|---|
| 服装 | 918 | 独立服饰图（无人体），含 Shopbop 白底商品图 98 件 |
| 上身实拍 | 452 | 模特 / 秀场实拍，单独分区以区别于独立服饰 |
| 人物 | 1,527 | 含发长（短发 742 / 中发 383 / 中长发 260 / 长发 142）与地区（国内 1,501 / 海外 26） |
| 分类 | 20 | 礼服正装、大衣外套、长袍斗篷、连衣裙、上衣、鞋履、裤装…… |

全部图片已本地化到 `assets/lib/`（2,897 张 webp，约 61 MB），不依赖外部图床。

## 本地预览

```bash
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/index.html
```

需通过 http 访问，直接双击 `file://` 打开会因浏览器安全策略导致部分数据加载失败。

## 部署

本目录即站点根目录，`index.html` 为入口。推送到仓库后开启 Pages 即可：

- Settings → Pages → Source 选 `Deploy from a branch`
- Branch 选 `main`，目录选 `/ (root)`

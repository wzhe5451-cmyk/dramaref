## 服饰提示词

每件服装配一组可直接喂给绘图模型的提示词，分中英两版。

**中文**按件分块成规格表，槽位跟着品类走，不套同一张表：

```markdown
**上装・奶油色女式衬衫**
- 颜色 / 面料 / 领型 / 袖型 / 衣身 / 腰部 / 门襟 / 车线 / 穿着状态

**下装・高腰微喇牛仔裤**
- 颜色 / 面料 / 版型 / 腰头 / 口袋 / 裤长 / 缝线 / 洗水效果

**整体质感**
- 光泽 / 褶皱 / 配色 / 饱和度
```

多件套按 上装 → 连衣裙 → 下装 → 鞋履 → 配饰 排序，末尾统一收在「整体质感」。

**英文**为单段成句 prompt，覆盖主体 / 面料 / 构造核对 / 置景 / 光位 / 景别 / 镜头 / 画质 / 风格锚点 / 负面约束。

工作台详情栏可一键复制中文或英文，侧栏底部可导出全库提示词 `.txt`。

一处已知局限：部分原始商品名不含颜色词，这些位置写的是「按参考帧取样主体布料色」，不做色值编造。

## 本地预览

```bash
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/index.html
```

需通过 http 访问。直接双击 `file://` 打开会因浏览器安全策略导致部分数据加载失败。

## 部署

本目录即站点根目录，`index.html` 为入口，已通过 GitHub Pages 发布：

- Settings → Pages → Source 选 `Deploy from a branch`
- Branch 选 `main`，目录选 `/ (root)`
- `.nojekyll` 已存在，确保 `js/` `css/` 不被 Jekyll 处理
